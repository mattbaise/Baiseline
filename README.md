# Baiseline

Official Baiseline website — developer tools, templates, automation, and resources.

## Local preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — homepage and site content
- `styles.css` — responsive Baiseline visual system
- `script.js` — mobile navigation and placeholder notifications

## Before launch

- Replace placeholder product links with final Gumroad URLs.
- Add real downloadable free resources.
- Confirm the preferred contact email for the Services CTA.

## Hosting

This is a static site and is ready for deployment with GitHub Pages or another static host.
