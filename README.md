# △ BAISELINE

### Build smarter. Ship faster.

Baiseline creates practical **developer tools, templates, automation, and free technical resources** designed to help developers move from idea to working software faster.

**Live site:** https://mattbaise.github.io/Baiseline/

---

## What you'll find here

- **Developer tools** — practical utilities and starter products for real workflows
- **Python & data** — automation, pipelines, cleaning, reporting, and analytics
- **API & backend** — FastAPI and backend starter resources
- **Databases** — PostgreSQL patterns, schemas, and database tooling
- **DevOps** — Docker and deployment-oriented resources
- **AI development** — starter patterns for LLM-enabled applications
- **Dashboards** — admin, reporting, and analytics interfaces

## Website

This repository contains the official Baiseline website. It is intentionally lightweight and dependency-free: plain HTML, CSS, and JavaScript deployed through GitHub Pages.

```bash
# local preview
git clone https://github.com/mattbaise/Baiseline.git
cd Baiseline
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
