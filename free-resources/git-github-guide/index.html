START

Create or Clone

git init
git status

git clone https://github.com/OWNER/REPO.git
cd REPO

git remote -v
DAILY

Daily Workflow

git status
git pull
git switch -c feature/my-change
# edit files
git diff
git add .
git commit -m "Add useful change"
git push -u origin feature/my-change
BRANCHES

Branch Commands

git branch
git branch -a
git switch main
git switch -c feature/name
git branch -d feature/name

git fetch --prune
INSPECT

Understand Changes

git status
git diff
git diff --staged
git log --oneline --decorate -10
git show HEAD
git blame path/to/file
UNDO

Safe Undo Patterns

# discard unstaged file change
git restore path/to/file

# unstage but keep changes
git restore --staged path/to/file

# reverse a shared commit safely
git revert COMMIT_SHA

Avoid destructive reset/force operations unless you understand their effect on shared history.

SYNC

Keep Current

git switch main
git pull origin main

git switch feature/my-change
git merge main
# resolve conflicts, then:
git add .
git commit
CONFLICTS

Merge Conflict Flow

  1. Run git status.
  2. Open conflicted files.
  3. Choose/combine the correct changes.
  4. Remove conflict markers.
  5. Run tests.
  6. git add resolved files.
  7. Complete the merge commit.
PR

Pull Request Checklist

  • Focused change with clear title.
  • Explain what changed and why.
  • Tests pass.
  • No secrets or generated junk.
  • Review the diff yourself first.
  • Address review comments.
  • Update docs when behavior changes.
