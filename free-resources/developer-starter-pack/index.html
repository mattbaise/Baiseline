CHECKLIST

Project Start → Ship Checklist

  • Define the problem and smallest useful scope.
  • Create repository and README.
  • Use an isolated environment and document dependencies.
  • Keep secrets outside source control.
  • Add validation and useful error handling.
  • Write tests for core behavior and important edge cases.
  • Run tests after changes and fix failures.
  • Test setup from a clean environment.
  • Document install, configuration, usage, examples, and troubleshooting.
  • Check security basics and production configuration.
DEBUG

Debugging Checklist

  1. Read the complete error.
  2. Reproduce it consistently.
  3. Reduce it to the smallest failing case.
  4. Check inputs, types, paths, config, and environment variables.
  5. Fix the cause, not just the symptom.
  6. Add a regression test and rerun the suite.
DEPLOY

Deployment Checklist

  • Tests pass.
  • No secrets are committed.
  • Production variables are documented.
  • Database migrations are ready.
  • Health check works.
  • Logs avoid sensitive data.
  • Build is reproducible.
  • README reflects the shipped version.
